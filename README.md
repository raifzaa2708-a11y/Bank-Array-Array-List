# Bank-Array-Array-List
F1D02510107-TUGAS PBO

# Maksud Pembuatan Program
Program ini dibuat untuk memenuhi tugas Pemrograman Berbasis Objek (PBO) materi Array & ArrayList, yang bertujuan untuk mengimplementasikan konsep struktur data dinamis dan pemodelan objek bertingkat (seperti relasi antara Bank, Nasabah, dan Rekening) dalam penyelesaian masalah nyata.

# Deskripsi Program
Program ini merupakan simulasi sistem perbankan dan transaksi ATM berbasis antarmuka baris perintah (Command Line Interface) yang memungkinkan pengguna untuk mengelola daftar nasabah, menambahkan rekening baru, serta melakukan berbagai transaksi finansial seperti cek saldo, setor tunai, dan tarik tunai secara interaktif.

# Library/Modul Tambahan
Program ini memanfaatkan dua pustaka standar bawaan Java (Java Standard Library), yaitu java.util.ArrayList untuk mengelola koleksi objek secara dinamis tanpa batasan ukuran tetap, serta java.util.Scanner untuk membaca dan memproses masukan teks maupun angka dari pengguna melalui terminal.
